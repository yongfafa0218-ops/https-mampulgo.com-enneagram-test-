# Mampulgo

Mampulgo is a React, Vite, Express, tRPC, Drizzle, and MySQL-compatible full-stack web application.

## What is included

The source code includes the browser client, the Express/tRPC server, Drizzle schema, tests, and the existing Manus OAuth and storage adapters. The project is now safe to upload to GitHub: runtime secrets and the exported Manus project configuration are intentionally excluded.

## Run locally

```bash
pnpm install
cp .env.example .env
# Fill in the values in .env
pnpm dev
```

The application needs a MySQL-compatible database for persisted data. The current authentication and file-storage adapters use Manus services. To run the full application outside Manus, provide valid Manus OAuth/Forge credentials or replace those adapters with an external authentication provider and object storage service.

## Build and start

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm start
```

The production server listens on `PORT` when supplied by the hosting provider and otherwise uses the port configured by the server runtime.

## Deploying

For the complete full-stack app, use a Node-capable service such as Render, Railway, Fly.io, or a comparable container host. Configure every variable in `.env.example` in the provider's secret/environment settings. Do not commit `.env`, `.project-config.json`, database URLs, OAuth secrets, or Forge keys.

The included `Dockerfile` builds and runs the full Express server. A static host such as Netlify or Vercel can host only the Vite frontend unless the backend API, database, authentication, and storage are deployed separately and the client API URL is configured accordingly.

## Manus-specific migration notes

The following areas are provider-specific and may require replacement when leaving Manus:

- Manus OAuth routes and session handling under `server/_core`.
- Manus Forge API calls used for storage and built-in services.
- Any `/manus-storage/` URLs generated by the storage adapter.
- The MySQL/TiDB database connection, which must be replaced by a database that your selected host can reach.

The frontend and ordinary TypeScript/React business logic remain portable.
